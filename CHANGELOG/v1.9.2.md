# v1.9.2

## Added
- **Direct `api_key` Configuration for AI Connections (`src/loki/config.py`, `src/loki/ai/chat.py`)**:
  - Support direct `api_key` specification in `.loki/config.yaml` (`ai.api_key`) and `.loki/models.json` profiles.
  - Enhanced `/model add` in `loki chat` to accept `api_key=<KEY>`, enabling one-step registration and activation of providers like OpenRouter, Anthropic, or OpenAI.
- **Enterprise-Grade GitHub Actions CI/CD Pipeline (`.github/workflows/loki.yml`)**:
  - Integrated `🔍 Lint & Code Standards (Ruff)` running in ~6 seconds with zero lint errors across `src` and `tests`.
  - Added `🔒 Security & Vulnerability Audit (pip-audit)` scanning the complete installed dependency tree for known CVEs.
  - Author a 7-leg cross-platform test matrix covering Ubuntu AMD64, Windows AMD64, and macOS ARM64 on Python 3.10, 3.11, and 3.12 (173 unit tests passing across all runners).
  - Added `📦 Standalone Binary Spec Smoke Test (loki.spec)` ensuring compiled PyInstaller binaries launch cleanly and pass CLI verification (`--help`, `version`).
  - Added workflow concurrency guards (`cancel-in-progress: true`) to prevent redundant CI run accumulation.

## Optimizations & Performance
- **Optimized PyInstaller Packaging Specification (`loki.spec`)**:
  - Pruned >860 static files and Prisma client assets (~50 MB) from `litellm.proxy` while surgically retaining necessary Python runtime code for spend tracking.
  - Excluded unused ASGI runtime and heavy libraries (`fastapi`, `starlette`, `uvicorn`, `matplotlib`, `scipy`, `pandas`) reducing standalone executable compile time by >40%.

## Bug Fixes
- **Missing `tenacity` Dependency in Packaging (`pyproject.toml`)**:
  - Added `tenacity>=8.2.0` to `[project.dependencies]` in `pyproject.toml` so global installations via `uv tool` and `pip` automatically provide LiteLLM retry handlers required by Anthropic and OpenRouter.
